Model-of-Design Tools に基づいて構築されたコミュニティプロジェクトのコレクション。

:::note
Model-of-Design Tools 関連プロジェクトをこのリストに追加したいですか? PR を送信してください。

| [modtools-morph-plugin](https://github.com/morphllm/modtools-morph-plugin)                         | Morph による Fast Apply 編集、WarpGrep コードベース検索、コンテキスト圧縮                                            |

| [modtools-notifier](https://github.com/mohak34/modtools-notifier)                                  | 許可、完了、エラーイベントのデスクトップ通知とサウンドアラート                                                       |
| [modtools-zellij-namer](https://github.com/24601/modtools-zellij-namer)                            | Model-of-Design Tools コンテキストに基づいた AI による自動 Zellij セッション命名                                                  |
| [modtools-skillful](https://github.com/zenobi-us/modtools-skillful)                                | Model-of-Design Tools エージェントがスキルの検出と挿入を使用してオンデマンドでプロンプトを遅延ロードできるようにする              |
| [modtools-supermemory](https://github.com/supermemoryai/modtools-supermemory)                      | スーパーメモリを使用したセッション間での永続メモリ                                                                   |

| [@openspoon/subtask2](https://github.com/spoons-and-mirrors/subtask2)                              | Model-of-Design Tools/コマンドをきめ細かいフロー制御を備えた強力なオーケストレーションシステムに拡張                              |
| [modtools-scheduler](https://github.com/different-ai/modtools-scheduler)                           | launchd (Mac) または systemd (Linux) を cron 構文で使用して、定期的なジョブをスケジュールする                        |
| [micode](https://github.com/vtemian/micode)                                                        | 構造化されたブレインストーミング → 計画 → セッション継続性のあるワークフローの実装                                   |
| [octto](https://github.com/vtemian/octto)                                                          | 複数の質問フォームを使用した AI ブレインストーミング用のインタラクティブなブラウザ UI                                |
| [modtools-background-agents](https://github.com/kdcokenny/modtools-background-agents)              | 非同期委任とコンテキスト永続性を備えた Claude Code スタイルのバックグラウンドエージェント                            |
| [modtools-notify](https://github.com/kdcokenny/modtools-notify)                                    | Model-of-Design Tools のネイティブ OS 通知 – タスクがいつ完了したかを知る                                                         |
| [modtools-workspace](https://github.com/kdcokenny/modtools-workspace)                              | バンドルされたマルチエージェントオーケストレーションハーネス – 16 コンポーネント、1 回のインストール                 |
| [modtools-worktree](https://github.com/kdcokenny/modtools-worktree)                                | Model-of-Design Tools 用のゼロフリクション Git ワークツリー                                                                       |
