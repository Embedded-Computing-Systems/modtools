ชุดโครงการชุมชนที่สร้างขึ้นบน Mod

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Mod ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-MOD](https://github.com/awesome-MOD/awesome-MOD) และ [MOD.cafe](https://MOD.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
