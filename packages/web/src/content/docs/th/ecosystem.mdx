ชุดโครงการชุมชนที่สร้างขึ้นบน Model-of-Design Tools

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Model-of-Design Tools ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-modtools](https://github.com/awesome-modtools/awesome-modtools) และ [modtools.cafe](https://modtools.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
