Every command accepts `--help` for its full flag list, for example `MOD run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ MOD run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: MOD review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @modtools-ai/cli
      - run: MOD run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ MOD run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ MOD run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ MOD run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ MOD run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ MOD run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ MOD run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ MOD run --auto "Fix the failing test"
```

View all subcommands and flags.

```bash
$ MOD run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ MOD mini
```

Continue the last session.

```bash
$ MOD mini --continue
```

Start with a model and an initial prompt.

```bash
$ MOD mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ MOD mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ MOD mini --help
```

## session

Manages sessions.

```bash
$ MOD session list
```

Limit the list and print JSON.

```bash
$ MOD session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ MOD session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ MOD session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ MOD session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ MOD session import session.json
```

Import into a specific directory.

```bash
$ MOD session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ MOD session --help
```

## auth

Manages AI providers and credentials.

```bash
$ MOD auth list
```

List them as JSON.

```bash
$ MOD auth list --format json
```

Log in to a provider.

```bash
$ MOD auth login anthropic
```

Log in with a specific authentication method.

```bash
$ MOD auth login anthropic --method key
```

Log out of a saved account.

```bash
$ MOD auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ MOD auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ MOD auth export anthropic > credentials.json
$ MOD auth import credentials.json
```

View all subcommands and flags.

```bash
$ MOD auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ MOD mcp list
```

Add a remote server.

```bash
$ MOD mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ MOD mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ MOD mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ MOD mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ MOD mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ MOD mcp logout sentry
```

View all subcommands and flags.

```bash
$ MOD mcp --help
```





```bash
$ MOD plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ MOD serve
```

Bind to all interfaces on a fixed port.

```bash
$ MOD serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ MOD serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ MOD serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ MOD pair
```

Use an external URL in the links.

```bash
$ MOD pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ MOD pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ MOD pair --remote --yes
```

View all subcommands and flags.

```bash
$ MOD pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ MOD service start
```

Restart it.

```bash
$ MOD service restart
```

Show its status.

```bash
$ MOD service status
```

Stop it.

```bash
$ MOD service stop
```

Read a setting.

```bash
$ MOD service get hostname
```

Set a setting.

```bash
$ MOD service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ MOD service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ MOD service set env MODTOOLS_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ MOD service unset hostname
```

View all subcommands and flags.

```bash
$ MOD service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ MOD reload
```

## api

Makes a request to the running server.

```bash
$ MOD api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ MOD api session.list --param limit=10
```

Send a JSON body.

```bash
$ MOD api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ MOD api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ MOD api --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ MOD debug agents
```

List configuration sources.

```bash
$ MOD debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ MOD debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ MOD debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ MOD debug paths
```

Print a single path.

```bash
$ MOD debug paths db
```

View all subcommands and flags.

```bash
$ MOD debug --help
```

## upgrade

Upgrades MOD to the latest or a specific version. Alias: `update`.

```bash
$ MOD upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ MOD upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ MOD upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls MOD. Session data, configuration, and
state are not removed.

```bash
$ MOD uninstall
```

Preview what would be removed.

```bash
$ MOD uninstall --dry-run
```

View all subcommands and flags.

```bash
$ MOD uninstall --help
```
